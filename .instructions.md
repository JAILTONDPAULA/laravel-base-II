# Padrões de Desenvolvimento - Base Laravel V2

Sempre siga estes padrões ao desenvolver neste projeto:

## 🚨 Regra Universal
**NUNCA execute comandos de terminal (artisan, npm, composer, etc.) sem perguntar antes ao usuário**
**NUNCA gere documentação README automaticamente - apenas quando explicitamente solicitado**

## 🟨 JavaScript

### Estrutura e Dependências
- O `app.js` sempre terá o jQuery carregado
- O `app.js` sempre será importado dentro das pages
- Use ES6+ (const/let, arrow functions, destructuring)
- Classes em PascalCase com documentação JSDoc
- Sempre tratar erros com try/catch

### Estrutura de Classes (OBRIGATÓRIO)
- **Todas as classes devem ter a propriedade `events`** com métodos `init` e `dom`
- **jQuery sempre disponível**: Eventos DOM devem partir de `$(document)`
- **init()**: Será chamado automaticamente em `$(document).ready()`
- **dom()**: Deve centralizar TODOS os eventos DOM e ser chamado no init
- **Inicialização automática**: `$(document).ready(() => NomeClasse.events.init())`

Estrutura OBRIGATÓRIA:
```javascript
export default class MinhaClasse {
    static events = {
        init() {
            console.log('MinhaClasse iniciada');
            MinhaClasse.events.dom();
            MinhaClasse.loadData();
        },
        
        dom() {
            // TODOS os eventos DOM aqui
            $(Recruitment school. document).on('click', '#meuBotao', MinhaClasse.metodo.acao);
            $(document).on('submit', '#meuForm', MinhaClasse.form.submit);
            $(document).on('keydown', MinhaClasse.events.handleKeydown);
        },
        
        handleKeydown(e) {
            if (e.key === 'Escape') {
                MinhaClasse.modal.close();
            }
        }
    }
    
    static metodo = {
        acao() { /* código */ }
    }
    
    static form = {
        submit(e) { /* código */ }
    }
}

// Inicialização automática
$(document).ready(() => {
    MinhaClasse.events.init();
});
```

### HTML Strings (IMPORTANTE)
Quando criar HTML strings em JavaScript:
- **Identar o código** 
- **Concatenar com + no final de cada linha**
- **Remover espaços mas manter a concatenação**

Exemplo correto:
```javascript
const html = '<div class="card">' +
            '<div class="card__header">' +
                '<h2 class="card__title">Título</h2>' +
            '</div>' +
            '<div class="card__content">' +
                '<p>Conteúdo aqui</p>' +
            '</div>' +
        '</div>';
```

### Organização e Nomenclatura
- **Organizar por classes**: Sempre estruturar o código em classes
- **Métodos relacionados**: Quando métodos estão relacionados (ex: #sym:openSidebar e #sym:closeSidebar), agrupar em propriedades estáticas
  ```javascript
  static sidebar = {
      open() { /* código */ },
      close() { /* código */ }
  }
  ```
- Variáveis e funções: `camelCase`
- Classes: `PascalCase`
- Constantes: `UPPER_SNAKE_CASE`
- Arquivos: `PascalCase.js`

## 🎨 Sass

### Padrão Cascata (OBRIGATÓRIO)
- **SEMPRE aninhar elementos filhos dentro do pai na estrutura de cascata**
- **NUNCA criar classes separadas** para elementos relacionados
- **Organizar @media queries em cascata dentro do elemento**
- **Cores definidas no arquivo app.sass**

Estrutura CORRETA - Cascata Real:
```sass
.container-principal
    background: var(--surface-card)
    padding: 1rem
    border-radius: var(--border-radius)
    
    .container__header
        border-bottom: 1px solid var(--surface-border)
        padding-bottom: 0.8rem
        
        .header__title
            font-size: 1.2rem
            color: var(--text-color)
            
            @media (max-width: 768px)
                font-size: 1rem
        
        .header__actions
            display: flex
            gap: 1rem
            
            .action__button
                background: var(--primary)
                color: white
                
                &:hover
                    background: var(--primary-dark)
        
        @media (max-width: 768px)
            padding-bottom: 0.5rem
    
    .container__content
        padding: 1rem 0
        
        .content__item
            margin-bottom: 0.5rem
            
            &.active
                background: var(--highlight)
    
    @media (max-width: 768px)
        padding: 0.8rem
```

Estrutura INCORRETA - Classes Separadas:
```sass
// ❌ NUNCA FAZER ASSIM
.container-principal
    background: var(--surface-card)

.container__header  // ❌ Separado do pai
    border-bottom: 1px solid var(--surface-border)

.header__title     // ❌ Separado do pai
    font-size: 1.2rem

.header__actions   // ❌ Separado do pai
    display: flex
```

### Sintaxe e Estrutura
- Usar sintaxe indentada (.sass) não SCSS
- Nomenclatura BEM (block__element--modifier)
- Organizar: _variables, _mixins, components/, pages/
- Mobile-first approach

### Variáveis de Cores
- **Todas as cores estão definidas no app.sass**
- Usar CSS Custom Properties do :root
- Referenciar cores através das variáveis definidas

## 🏷️ HTML/Blade

### Semântica e Componentes
- Sempre usar elementos semânticos (header, nav, main, section)
- Criar componentes Blade reutilizáveis em components/
- Classes seguindo metodologia BEM
- Incluir ARIA labels e alt texts para acessibilidade

### Performance
- Meta tags otimizadas
- Preconnect para recursos externos
- Lazy loading quando apropriado

## 📁 Estrutura de Arquivos
```
resources/
├── js/
│   ├── app.js          // Entry point com jQuery
│   ├── class/          // Classes utilitárias
│   ├── components/     // Componentes JS
│   └── pages/          // Scripts por página (importam app.js)
├── sass/
│   ├── app.sass        // Cores e variáveis principais
│   ├── components/     // Estilos de componentes (cascata)
│   └── pages/          // Estilos por página (cascata)
└── views/
    ├── components/     // Componentes Blade
    └── pages/          // Views específicas
```
