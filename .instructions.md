# Padrões de Desenvolvimento - Base Laravel V2

Sempre siga estes padrões ao desenvolver neste projeto:

## 🚨 Regra Universal
**NUNCA execute comandos de terminal (artisan, npm, composer, etc.) sem perguntar antes ao usuário**

## 🟨 JavaScript

### Estrutura e Dependências
- O `app.js` sempre terá o jQuery carregado
- O `app.js` sempre será importado dentro das pages
- Use ES6+ (const/let, arrow functions, destructuring)
- Classes em PascalCase com documentação JSDoc
- Sempre tratar erros com try/catch

### HTML Strings (IMPORTANTE)
Quando criar HTML strings em JavaScript:
- **Identar o código** 
- **Concatenar com + no final de cada linha**
- **Remover espaços mas manter a concatenação**

Exemplo correto:
```javascript
const html = '<div class="card">' +
            '<div class="card__header">' +
                '<h2 class="card__title">Título</h2>' +
            '</div>' +
            '<div class="card__content">' +
                '<p>Conteúdo aqui</p>' +
            '</div>' +
        '</div>';
```

### Organização e Nomenclatura
- **Organizar por classes**: Sempre estruturar o código em classes
- Variáveis e funções: `camelCase`
- Classes: `PascalCase`
- Constantes: `UPPER_SNAKE_CASE`
- Arquivos: `PascalCase.js`

## 🎨 Sass

### Padrão Cascata (OBRIGATÓRIO)
- **Sempre desenvolver no padrão cascata**
- **Organizar @media queries em cascata dentro do elemento**
- **Cores definidas no arquivo app.sass**

Exemplo correto:
```sass
.card
    background: var(--surface-card)
    padding: 1rem
    border-radius: var(--border-radius)
    
    &__header
        border-bottom: 1px solid var(--surface-border)
        padding-bottom: 0.8rem
        
        @media (max-width: 768px)
            padding-bottom: 0.5rem
    
    &__title
        font-size: 1.2rem
        color: var(--text-color)
        
        @media (max-width: 768px)
            font-size: 1rem
    
    @media (max-width: 768px)
        padding: 0.8rem
```

### Sintaxe e Estrutura
- Usar sintaxe indentada (.sass) não SCSS
- Nomenclatura BEM (block__element--modifier)
- Organizar: _variables, _mixins, components/, pages/
- Mobile-first approach

### Variáveis de Cores
- **Todas as cores estão definidas no app.sass**
- Usar CSS Custom Properties do :root
- Referenciar cores através das variáveis definidas

## 🏷️ HTML/Blade

### Semântica e Componentes
- Sempre usar elementos semânticos (header, nav, main, section)
- Criar componentes Blade reutilizáveis em components/
- Classes seguindo metodologia BEM
- Incluir ARIA labels e alt texts para acessibilidade

### Performance
- Meta tags otimizadas
- Preconnect para recursos externos
- Lazy loading quando apropriado

## 📁 Estrutura de Arquivos
```
resources/
├── js/
│   ├── app.js          // Entry point com jQuery
│   ├── class/          // Classes utilitárias
│   ├── components/     // Componentes JS
│   └── pages/          // Scripts por página (importam app.js)
├── sass/
│   ├── app.sass        // Cores e variáveis principais
│   ├── components/     // Estilos de componentes (cascata)
│   └── pages/          // Estilos por página (cascata)
└── views/
    ├── components/     // Componentes Blade
    └── pages/          // Views específicas
```
